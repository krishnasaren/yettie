About

Welcome to Yettie Professional v3.0

Yettie Professional is an advanced security testing platform designed for web application penetration testers and security researchers.

Quick Start Guide:

  1. Set your target: Go to the Target tab and configure your scope
  2. Configure proxy: Set up your browser to use Yettie as a proxy (127.0.0.1:8080)
  3. Start browsing: Browse your target application to capture requests
  4. Analyze: Use the Scanner and other tools to identify vulnerabilities
  5. Test: Use Repeater and Intruder to manually test findings

Key Features:

  • Advanced web vulnerability scanner
  • Powerful intruder for automated attacks
  • Repeater for manual request manipulation
  • Decoder for various encoding/decoding operations
  • Collaborator for out-of-band testing
  • Extensive extension support

Tools Reference

Proxy

Intercept and modify HTTP/HTTPS traffic between your browser and target applications.

Scanner

Automatically scan web applications for common vulnerabilities including SQL injection, XSS, CSRF, and more.

Intruder

Perform customized automated attacks to identify and exploit vulnerabilities.

Repeater

Manually edit and reissue individual HTTP requests.

Decoder

Encode and decode data using various algorithms and formats.

Comparer

Compare two pieces of data to identify differences.

Collaborator

Detect and exploit out-of-band vulnerabilities.

Common Issues & Solutions

Proxy Not Working

  • Verify Yettie is running and listening on the correct port (default: 8080)
  • Check browser proxy settings are correctly configured
  • Ensure no other application is using port 8080
  • Try disabling SSL verification if HTTPS sites aren't loading

Scanner Not Finding Vulnerabilities

  • Ensure you have proper authorization to test the target
  • Check that the target is within the configured scope
  • Try increasing scan depth and coverage
  • Verify the application is actually vulnerable to tested issues

Application Crashes or Freezes

  • Increase Java heap size in Advanced Settings
  • Clear temporary files and restart
  • Check available system memory
  • Update to the latest version
